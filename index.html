Первичная настройка

Сначала создайте постоянный секрет для этого экземпляра приложения и добавьте его в Google Authenticator.

Google Authenticator

Это секрет вашего экземпляра VaultText. Он хранится локально как неэкспортируемый криптографический ключ.

Добавьте вручную в Google Authenticator
  1. Добавьте новый аккаунт.
  2. Выберите ввод ключа настройки вручную.
  3. Вставьте показанный Base32-ключ.
  4. Тип ключа: Time based.

Если сбросить данные сайта, этот экземпляр потеряет локальный секрет. Не удаляйте его, пока не убедились, что у вас есть способ восстановить доступ.

TOTP проверяется локально. Сам код в шифр-код не записывается.

Модель защиты

  • Текст шифруется AES-256-GCM.
  • Для каждого сообщения создаётся новый случайный 256-битный ключ.
  • Постоянный TOTP-секрет хранится локально как неэкспортируемый HMAC CryptoKey.
  • Текущий 6-значный TOTP-код проверяется перед каждой операцией.
  • Шифр-код не содержит TOTP-секрет.
  • Нет сервера, аналитики, CDN и сторонних библиотек.
  • После первого запуска PWA может работать без сети.

Важно: браузер не предоставляет универсальной гарантии аппаратной привязки IndexedDB к конкретному устройству. Для особо критичных данных нужен независимый аудит и/или аппаратный ключ.

Все операции выполняются на этом устройстве.
